## Runtime safety and freshness
Only NSClassFromString(TT100), respondsToSelector, NSMethodSignature argument/return encodings, exact id(*)(id,SEL) objc_msgSend and exception protection. Main-thread light getter only; no startMonitoring/refresh/IPC/model/daemon/library loading, copying or linking. Missing class, selector/type mismatch, nil snapshot and every validation failure are fallback, not crashes.

Auto source adopts the producer's apple/jikan source and its explicit target; legacy preference cannot reject a valid source. require available + hasEstimate + charging/external + not full/targetReached; finite positive seconds <=86400; integer target 1..100; displayPercent 0..100 and below target. UI ring uses UIDevice actual battery percent, not ETA/displayPercent progress.

No producer timestamp is assumed. An ordinary getter establishes an identity baseline but cannot make data fresh. Only a changed dictionary identity witnessed at the final producer publication grants freshness (monotonic observation age <=300 seconds). Unchanged old dictionary notifications never renew that age. Session invalidation on unplug, disabled switch or missing source rejects reuse/late results; identity baseline is strongly retained to prevent pointer-address reuse. No timer/display-link; expiry is enforced on the next event-driven read/currentSnapshot access, not by a background ticking UI.
